# tradelingo-app
TradeLingo è un’applicazione web interattiva e gamificata per imparare il trading. Combina un corso a livelli in stile Duolingo (quiz e sfide su grafici) con una piattaforma di simulazione live in cui puoi fare trading con soldi virtuali e iniettare eventi di mercato (fake news, balene, alta volatilità) per testare le tue abilità.
